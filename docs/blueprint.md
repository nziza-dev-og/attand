# **App Name**: AttendEase

## Core Features:

- Role-Based Dashboards: Role-based dashboards (Admin, Teacher, Parent) with specific functionalities.
- Attendance Marking: Attendance marking interface for teachers to record student attendance (present, absent, late).
- Attendance Reporting: Attendance reports generation for admins and parents to view attendance history and summaries.

## Style Guidelines:

- Primary color: Light blue (#E0F7FA) for a calm and trustworthy feel.
- Secondary color: Soft gray (#F5F5F5) for backgrounds and neutral elements.
- Accent: Teal (#008080) for interactive elements and highlights.
- Clear and readable sans-serif fonts for all text elements.
- Simple and recognizable icons for navigation and actions.
- Clean and organized layout with clear sections for each role.
